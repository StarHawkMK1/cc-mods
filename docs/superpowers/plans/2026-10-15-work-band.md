# work-band Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 프롬프트 위 한 줄 막대에 superpowers 흐름 단계(또는 Claude 할 일 목록) 진행과 실행 중인 서브에이전트 수를 추가 토큰 없이 보여 주는 mod `work-band`를 만든다.

**Architecture:** 순수 로직(`flow.ts`: 할 일 목록, 단계 기계, 막대 계산), 비용 계산(`agents.ts`), 그리기(`draw.ts`: SVG 막대·크랩·패널 행), 문자열(`i18n.ts`)을 모듈로 나누고, `work-band.tsx`가 훅을 연결한다. 훅은 이미 일어나는 이벤트(`tool.call`의 Skill/TodoWrite/TaskCreate/TaskUpdate/Write/Edit/NotebookEdit, `prompt.submit`, `agent.spawn`, `turn.step`, `turn.complete`)를 읽기만 하고 결과를 바꾸지 않는다. 그리기·패널·비용 코드는 savvy-progress(johnnyvizz/claude-kit, MIT)에서 차용한다.

**Tech Stack:** Claude Code mod 훅 API(`claude-code`), TSX/TS 모듈(상대 import 가능), 테스트 키트 `claude-code/testing` (`claude plugin test`)

**Spec:** `docs/superpowers/specs/2026-10-15-work-band-design.md`

## Global Constraints

- 추가 토큰 0: `$.tool.register` 금지, 프롬프트·컨텍스트 수정 금지. 훅은 `next(e)`의 결과를 그대로 돌려준다.
- 단계 신호와 메인 할 일 목록은 메인 세션(`e.agentId` 없음)의 것만 쓴다. 서브에이전트의 할 일 목록은 패널용으로 `agentId`별로 따로 모은다.
- 다른 훅이 거부했거나(`deny`) 오류(`isError`)인 도구 호출, `success === false`인 결과는 무시한다.
- 목록 최대 200개(`MAX_TODOS`), 글자 120자(`MAX_TEXT`), 넘으면 `…`로 자른다.
- 언어: `en`, `ko`. 설정 `language`(`auto`/`en`/`ko`).
- mod 이름 `work-band`, 패널 id `work-band-agents`, 명령 `/work-band`, 버전 0.1.0.
- 테스트는 `claude plugin test ./mods/work-band`, 검증은 `claude plugin validate ./mods/work-band`와 `claude plugin validate .`.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```ts
import type { On } from 'claude-code'
import { mock } from 'claude-code/testing'
import type { Engine } from 'claude-code/testing'

export const PLUGIN = 'work-band'
export const PANE = 'work-band-agents'
export const SURFACES = ['terminal', 'desktop'] as const
export type Surface = (typeof SURFACES)[number]
export const BAND = { hasSurvey: false, isWorking: false, maxRows: 4, bodyColumns: 100, scroll: { offset: 0, bodyRows: 4 }, view: {} }
export const PANE_PROPS = { title: '', isFocused: false, bodyColumns: 60, placement: 'dock', scroll: { offset: 0, bodyRows: 30 }, view: {} } as const

// The world beneath the mod: a clock, nothing else drawing the band, panes that
// open and close, files from `files`, and tools, prompts and subagents that succeed.
export function world(on: On, now = 1_000, files: Record<string, string> = {}) {
  const clock = mock.clock(on, { now })
  on('ui.render', () => ({ type: 'engine' }) as never)
  let panes: { id: string; title: string }[] = []
  on('ui.panes', () => ({ value: panes }) as never)
  on('ui.open', (_$, e) => {
    const { id, title } = e as { id: string; title?: string }
    panes = [...panes.filter(p => p.id !== id), { id, title: title ?? '' }]
    return { value: { isPlaced: true } } as never
  })
  on('ui.close', (_$, e) => {
    panes = panes.filter(p => p.id !== (e as { id: string }).id)
    return { value: undefined } as never
  })
  on('fs.read', (_$, e) => {
    const path = (e as { path: string }).path.replace(/\\/g, '/')
    const hit = Object.keys(files).find(k => path.endsWith(k))
    if (hit === undefined) throw new Error(`ENOENT: ${path}`)
    return { value: files[hit] } as never
  })
  on('tool.call', { tool: 'TodoWrite' }, () => ({ result: { oldTodos: [], newTodos: [] } }) as never)
  let lastId = 0
  on('tool.call', { tool: 'TaskCreate' }, () => ({ result: { task: { id: String(++lastId), subject: '' } } }) as never)
  on('tool.call', { tool: 'TaskUpdate' }, (_$, e) => ({ result: { success: true, taskId: (e as { taskId: string }).taskId, updatedFields: [] } }) as never)
  on('tool.call', { tool: 'Skill' }, (_$, e) => ({ result: { success: true, commandName: (e as { skill: string }).skill } }) as never)
  on('tool.call', { tool: 'Write' }, () => ({ result: {} }) as never)
  on('tool.call', { tool: 'Edit' }, () => ({ result: {} }) as never)
  on('prompt.submit', (_$, e) => ({ text: e.text }) as never)
  on('agent.spawn', (_$, e) => ({ model: 'claude-opus-5-5', agentId: `ag-${e.tool_use_id}` }) as never)
  on('turn.complete', () => ({ text: '' }) as never)
  return { clock, panes: () => panes }
}

// The band above the prompt as text: the terminal's Text runs joined, or the
// desktop row's SVG source; null when the mod draws nothing there.
export async function band($: Engine, surface: Surface): Promise<string | null> {
  try {
    const ui = await $.ui.mount({ plugin: PLUGIN, surface, component: 'AbovePrompt', props: BAND })
    const svg = await ui.find({ type: 'Svg' })
    const texts = await ui.findAll({ type: 'Text' })
    await ui.unmount()
    return surface === 'desktop' ? String(svg?.props.source) : texts.map(t => t.text).join(' | ')
  } catch (err) {
    if (/drew nothing/.test(String(err))) return null
    throw err
  }
}

const by = (agentId?: string) => (agentId ? { agentId } : {})

export const todoWrite = ($: Engine, todos: unknown[], agentId?: string) =>
  $.tool.call({ tool: 'TodoWrite', todos, ...by(agentId) } as never)
export const taskCreate = ($: Engine, subject: string, activeForm?: string, agentId?: string) =>
  $.tool.call({ tool: 'TaskCreate', subject, description: subject, ...(activeForm ? { activeForm } : {}), ...by(agentId) } as never)
export const taskUpdate = ($: Engine, taskId: string, fields: Record<string, unknown>) =>
  $.tool.call({ tool: 'TaskUpdate', taskId, ...fields } as never)
export const skill = ($: Engine, name: string, args?: string, agentId?: string) =>
  $.tool.call({ tool: 'Skill', skill: name, ...(args ? { args } : {}), ...by(agentId) } as never)
export const write = ($: Engine, file_path: string, content = '', agentId?: string) =>
  $.tool.call({ tool: 'Write', file_path, content, ...by(agentId) } as never)
export const spawn = ($: Engine, id: string, description = `Job ${id}`) =>
  $.agent.spawn({
    tool_use_id: id,
    prompt: 'p',
    description,
    subagentType: 'general-purpose',
    provider: 'engine',
    parentModel: 'claude-opus-5-5',
    background: false,
    fork: false,
  } as never)
export const finish = ($: Engine, id: string) =>
  ($.turn.complete as (e: unknown) => Promise<unknown>)({ agentId: `ag-${id}`, reason: 'answer', answer: 'ok', usage: null })
export const endTurn = ($: Engine) =>
  ($.turn.complete as (e: unknown) => Promise<unknown>)({ reason: 'answer', answer: 'ok', usage: null })
export const submit = ($: Engine, text: string, extra: Record<string, unknown> = {}) =>
  ($.prompt.submit as (e: unknown) => Promise<unknown>)({ text, wait: false, origin: { kind: 'composer' }, ...extra })
```

```tsx
import type { EngineInterface, Register } from 'claude-code'

import { STRINGS, langOf, type Lang } from './i18n'

// Module scope is fine: session.start sets it on every (re)load.
let lang: Lang = 'en'
export const tr = () => STRINGS[lang]

async function detectLang($: EngineInterface, option: unknown): Promise<Lang> {
  if (option === 'en' || option === 'ko') return option
  try {
    const settings = (await $.settings.read()) as Record<string, unknown>
    if (typeof settings.language === 'string' && settings.language.trim()) return langOf(settings.language)
  } catch {
    // No settings: the locale decides.
  }
  const locale = (await $.env.get('LC_ALL')) || (await $.env.get('LC_MESSAGES')) || (await $.env.get('LANG'))
  return langOf(locale)
}

export const register: Register = (on, options) => {
  on('session.start', async ($, e, next) => {
    const started = await next(e)
    lang = await detectLang($, options.language)
    return started
  })
}
```

```ts
import type { AgentRun, Todo, TodoStatus, Work } from '../types'

export const MAX_TODOS = 200
export const MAX_TEXT = 120

export const blankWork = (): Work => ({ flow: null, todos: [], agentTodos: {}, since: 0, isHidden: false })

export const clip = (s: string, max: number): string => (s.length > max ? s.slice(0, Math.max(1, max - 1)) + '…' : s)

export const cleanText = (v: unknown): string | undefined =>
  typeof v === 'string' && v.trim() ? clip(v.trim(), MAX_TEXT) : undefined

const STATUSES: readonly TodoStatus[] = ['pending', 'in_progress', 'completed']

export const statusOr = (v: unknown, fallback: TodoStatus): TodoStatus => STATUSES.find(s => s === v) ?? fallback

// ---------------------------------------------------------------------------
// To-do lists: TodoWrite replaces a list, TaskCreate/TaskUpdate keep it row by row.

type TodoInput = { content?: unknown; status?: unknown; activeForm?: unknown }

export const cleanTodos = (todos: unknown): Todo[] =>
  (Array.isArray(todos) ? (todos as TodoInput[]) : [])
    .filter(t => cleanText(t?.content))
    .slice(0, MAX_TODOS)
    .map((t, i) => ({
      id: String(i + 1),
      title: cleanText(t.content) ?? '',
      activeForm: cleanText(t.activeForm),
      status: statusOr(t.status, 'pending'),
    }))

// A new pending row; null when the call carried no id or no subject.
export const createTodo = (todos: Todo[], id: unknown, subject: unknown, activeForm: unknown): Todo[] | null => {
  const title = cleanText(subject)
  if (typeof id !== 'string' || !id || !title) return null
  const row: Todo = { id, title, activeForm: cleanText(activeForm), status: 'pending' }
  return [...todos.filter(t => t.id !== id), row].slice(-MAX_TODOS)
}

export type TaskUpdateInput = { taskId?: unknown; status?: unknown; subject?: unknown; activeForm?: unknown }

// The list with that row changed or removed; null for a row it never saw.
export const updateTodo = (todos: Todo[], input: TaskUpdateInput): Todo[] | null => {
  if (!todos.some(t => t.id === input.taskId)) return null
  if (input.status === 'deleted') return todos.filter(t => t.id !== input.taskId)
  return todos.map(t =>
    t.id !== input.taskId
      ? t
      : {
          ...t,
          status: statusOr(input.status, t.status),
          title: cleanText(input.subject) ?? t.title,
          activeForm: cleanText(input.activeForm) ?? t.activeForm,
        },
  )
}

// The list a to-do call changes: the main session's, or that subagent's.
export const listOf = (w: Work, agentId?: string): Todo[] =>
  agentId ? (Object.hasOwn(w.agentTodos, agentId) ? (w.agentTodos[agentId] ?? []) : []) : w.todos

// A change to the main list brings a dismissed band back.
export const withList = (w: Work, agentId: string | undefined, todos: Todo[]): Work =>
  agentId ? { ...w, agentTodos: { ...w.agentTodos, [agentId]: todos } } : { ...w, todos, isHidden: false }

export const doingOf = (todos: Todo[]): string | undefined => {
  const active = todos.find(t => t.status === 'in_progress')
  return active?.activeForm || active?.title
}

export type Steps = { done: number; total: number; note?: string }

export const stepsOf = (todos: Todo[]): Steps | null =>
  todos.length ? { done: todos.filter(t => t.status === 'completed').length, total: todos.length, note: doingOf(todos) } : null

// ---------------------------------------------------------------------------
// Requests: a prompt typed while idle.

// A finished flow and a finished list go; the subagents shown are counted from now.
export const startRequest = (w: Work, at: number): Work => ({
  ...w,
  flow: w.flow?.isFinished ? null : w.flow,
  todos: w.todos.every(t => t.status === 'completed') ? [] : w.todos,
  since: at,
})

// This request's subagents: still running, or started since it began.
export const requestAgents = (list: AgentRun[], since: number): AgentRun[] =>
  list.filter(a => a.status === 'running' || a.startedAt >= since)
```

```ts
// ---------------------------------------------------------------------------
// The superpowers flow: skills set the stage, files written fill in the rest.

export const STAGES: readonly Stage[] = ['brainstorm', 'spec', 'plan', 'build', 'review', 'finish']

const SKILL_STAGE: Record<string, Stage> = {
  brainstorming: 'brainstorm',
  'writing-plans': 'plan',
  'subagent-driven-development': 'build',
  'executing-plans': 'build',
  'test-driven-development': 'build',
  'requesting-code-review': 'review',
  'finishing-a-development-branch': 'finish',
}

// The stage a superpowers skill starts, or null for any other skill.
export const skillStage = (name: unknown): Stage | null => {
  if (typeof name !== 'string') return null
  const key = /^\/?superpowers:([\w-]+)$/.exec(name.trim())?.[1]
  return key && Object.hasOwn(SKILL_STAGE, key) ? (SKILL_STAGE[key] ?? null) : null
}

const firstLine = (s: unknown): string | undefined =>
  typeof s === 'string' ? cleanText(s.split(/\r?\n/).find(l => l.trim())) : undefined

// Brainstorming always starts a new flow; any other skill starts one when there
// is none or it finished, and otherwise only moves it forward.
export const advance = (flow: Flow | null, stage: Stage, args?: unknown): Flow => {
  if (stage === 'brainstorm') {
    const topic = firstLine(args)
    return topic ? { stage, isFinished: false, topic } : { stage, isFinished: false }
  }
  if (!flow || flow.isFinished) return { stage, isFinished: false }
  return STAGES.indexOf(stage) > STAGES.indexOf(flow.stage) ? { ...flow, stage } : flow
}

const slash = (p: string): string => p.replace(/\\/g, '/')

const isUnder = (path: string, dir: string): boolean => {
  const p = slash(path)
  return p.startsWith(dir) || p.includes(`/${dir}`)
}

const SPECS = 'docs/superpowers/specs/'
const PLANS = 'docs/superpowers/plans/'
// Writing here does not mean the build began: the flow's own docs, the visual
// companion's folder, Claude's own settings and memory.
const NOT_BUILD = ['docs/superpowers/', '.superpowers/', '.claude/']

export const heading = (md: string): string | undefined => firstLine(/^#[ \t]+(.+)$/m.exec(md)?.[1])

export const countTasks = (md: string): number => (md.match(/^###[ \t]+Task\b/gm) ?? []).length

const planTitleOf = (md: string): string | undefined => heading(md)?.replace(/\s+Implementation Plan$/i, '') || undefined
const specTitleOf = (md: string): string | undefined => heading(md)?.replace(/\s+(설계|Design)$/i, '') || undefined

// The plan's title and task count, where the text has them.
export const withPlan = (flow: Flow, md: string): Flow => {
  const title = planTitleOf(md)
  const tasks = countTasks(md)
  return { ...flow, ...(title ? { planTitle: title } : {}), ...(tasks ? { planTasks: tasks } : {}) }
}

// A file the main session wrote or edited (`content` is Write's): the spec
// moves Brainstorm to Spec, the plan gives title and task count, and any other
// file in Brainstorm or Spec means the build began without a plan.
export const onWrite = (flow: Flow | null, path: unknown, content?: unknown): Flow | null => {
  if (!flow || flow.isFinished || typeof path !== 'string') return flow
  const text = typeof content === 'string' ? content : undefined
  const isMd = slash(path).toLowerCase().endsWith('.md')
  if (isMd && isUnder(path, SPECS)) {
    const next: Flow = flow.stage === 'brainstorm' ? { ...flow, stage: 'spec' } : flow
    const title = text ? specTitleOf(text) : undefined
    return title ? { ...next, specTitle: title } : next
  }
  if (isMd && isUnder(path, PLANS)) return text ? withPlan(flow, text) : flow
  if (NOT_BUILD.some(dir => isUnder(path, dir))) return flow
  return flow.stage === 'brainstorm' || flow.stage === 'spec' ? { ...flow, stage: 'build' } : flow
}

// A `.md` path in a skill's arguments: the plan an executing skill was handed.
export const mdPathOf = (args: unknown): string | undefined =>
  typeof args === 'string' ? /[^\s"'`]+\.md\b/i.exec(args)?.[0] : undefined
```

```ts
// ---------------------------------------------------------------------------
// What the band draws.

export type Bar = {
  title: string
  /** The label riding the head of the fill. */
  pill: string
  /** Filled share, 0..1. */
  ratio: number
  /** Filled plus in-progress share, 0..1: the faint second layer. */
  runRatio: number
  /** Where ticks go, as shares of the bar. */
  ticks: number[]
  isFinished: boolean
  /** The superpowers flow's band (✕ ends it) or the harness's (✕ hides it). */
  isFlow: boolean
  /** What is in progress now, for the alt text. */
  doing: string
}

const doneCount = (todos: Todo[]): number => todos.filter(t => t.status === 'completed').length
const busyCount = (todos: Todo[]): number => todos.filter(t => t.status === 'in_progress').length

const evenTicks = (n: number): number[] => (n > 1 && n <= 50 ? Array.from({ length: n - 1 }, (_, i) => (i + 1) / n) : [])

// Six equal stages; inside Build the share of tasks done fills its own stage.
export const flowBar = (flow: Flow, todos: Todo[], s: Strings): Bar => {
  const n = STAGES.length
  const at = STAGES.indexOf(flow.stage)
  const isBuild = flow.stage === 'build'
  const total = flow.planTasks || todos.length
  const done = Math.min(total, doneCount(todos))
  const inner = isBuild && total ? done / total : 0
  // The stage being worked shows faintly: in Build the tasks in progress, elsewhere the whole stage.
  const ahead = isBuild && total ? Math.min(total - done, busyCount(todos)) / total : 1
  return {
    title: flow.planTitle ?? flow.specTitle ?? flow.topic ?? doingOf(todos) ?? s.superpowers,
    pill: flow.isFinished ? s.done : isBuild && total ? `${s.stage.build} ${done}/${total}` : s.stage[flow.stage],
    ratio: flow.isFinished ? 1 : (at + inner) / n,
    runRatio: flow.isFinished ? 1 : Math.min(1, (at + inner + ahead) / n),
    ticks: evenTicks(n),
    isFinished: flow.isFinished,
    isFlow: true,
    doing: doingOf(todos) ?? '',
  }
}

export const todoBar = (todos: Todo[], s: Strings): Bar | null => {
  if (!todos.length) return null
  const done = doneCount(todos)
  const isFinished = done === todos.length
  const pending = todos.find(t => t.status !== 'completed')
  return {
    title: doingOf(todos) || pending?.title || todos.at(-1)?.title || s.tasks,
    pill: isFinished ? s.done : `${s.tasks} ${done}/${todos.length}`,
    ratio: done / todos.length,
    runRatio: (done + busyCount(todos)) / todos.length,
    ticks: evenTicks(todos.length),
    isFinished,
    isFlow: false,
    doing: doingOf(todos) ?? '',
  }
}

// Ended counts failures too: a failed run is no longer working.
export const agentsBar = (runs: AgentRun[], s: Strings): Bar | null => {
  if (!runs.length) return null
  const running = runs.filter(a => a.status === 'running').length
  const ended = runs.length - running
  return {
    title: s.subagents,
    pill: running ? `${s.agents} ${ended}/${runs.length}` : s.done,
    ratio: ended / runs.length,
    runRatio: 1,
    ticks: evenTicks(runs.length),
    isFinished: running === 0,
    isFlow: false,
    doing: '',
  }
}

// The flow when there is one; else, unless dismissed, the main list, else this request's subagents.
export const pickBar = (w: Work, runs: AgentRun[], s: Strings): Bar | null => {
  if (w.flow) return flowBar(w.flow, w.todos, s)
  if (w.isHidden) return null
  return todoBar(w.todos, s) ?? agentsBar(requestAgents(runs, w.since), s)
}
```

```ts
// Prices, model names and formats borrowed from savvy-progress
// (johnnyvizz/claude-kit, MIT; see THIRD_PARTY_NOTICES.md).
import type { AgentRun } from '../types'

// USD per million tokens: input, output, cache read, cache write. The first row
// that matches a model id wins, so a release sits above its family. The engine
// reports tokens, not money, so cost is an estimate; cache writes are priced at
// the 1-hour rate (2x input), which Claude Code writes on a subscription.
type Price = [input: number, output: number, cacheRead: number, cacheWrite: number]

const PRICES: [RegExp, Price][] = [
  [/(fable|mythos)-5-1/, [10, 50, 0.25, 20]],
  [/fable|mythos/, [10, 50, 1, 20]],
  [/opus-5-5/, [4, 20, 0.2, 8]],
  [/opus/, [5, 25, 0.5, 10]],
  [/sonnet-5-5/, [2, 10, 0.1, 4]],
  [/sonnet-5/, [2, 10, 0.2, 4]],
  [/sonnet/, [3, 15, 0.3, 6]],
  [/haiku-5-5/, [0.1, 0.5, 0.01, 0.2]],
  [/haiku/, [1, 5, 0.1, 2]],
]

// Haiku 5.5 is priced by prompt length: a request whose prompt (input, cache
// reads and cache writes together) is over 100,000 tokens pays these instead.
const HAIKU_LONG_PROMPT = 100_000
const HAIKU_LONG: Price = [0.5, 2.5, 0.05, 1]

export type Usage = {
  input_tokens: number
  output_tokens: number
  cache_read_input_tokens: number
  cache_creation_input_tokens: number
}

const priceOf = (model: string, prompt: number): Price => {
  const id = model.toLowerCase()
  if (prompt > HAIKU_LONG_PROMPT && /haiku-5-5/.test(id)) return HAIKU_LONG
  return PRICES.find(([re]) => re.test(id))?.[1] ?? [4, 20, 0.2, 8]
}

export const usageTokens = (u: Usage): number =>
  (u.input_tokens || 0) + (u.output_tokens || 0) + (u.cache_read_input_tokens || 0) + (u.cache_creation_input_tokens || 0)

// `isRequest`: the usage is one model request, which a prompt-length price is set by.
export const costOf = (model: string, u: Usage, isRequest: boolean): number => {
  const prompt = isRequest ? (u.input_tokens || 0) + (u.cache_read_input_tokens || 0) + (u.cache_creation_input_tokens || 0) : 0
  const [i, o, r, w] = priceOf(model, prompt)
  return ((u.input_tokens || 0) * i + (u.output_tokens || 0) * o + (u.cache_read_input_tokens || 0) * r + (u.cache_creation_input_tokens || 0) * w) / 1e6
}

// Haiku 4.5 and the Claude 3 models have a 200K window; the rest 1M.
export const windowOf = (model: string): number => (/haiku-4|claude-3/i.test(model) ? 200_000 : 1_000_000)

export const modelName = (id: string): string => {
  const m = /(fable|mythos|opus|sonnet|haiku)-(\d+)(?:-(\d{1,2})(?!\d))?/i.exec(id)
  const [, family = '', major = '', minor] = m ?? []
  if (!family) return id.replace(/^claude-/, '').replace(/\[.*\]$/, '') || '—'
  return `${family.charAt(0).toUpperCase()}${family.slice(1).toLowerCase()} ${major}${minor ? '.' + minor : ''}`
}

export const runModel = (a: AgentRun): string => (a.effort ? `${modelName(a.model)} · ${a.effort}` : modelName(a.model))

export const fmtTokens = (n: number): string =>
  n >= 1e6 ? `${(n / 1e6).toFixed(1)}M` : n >= 1e3 ? `${Math.round(n / 1e3)}k` : `${Math.round(n)}`

export const fmtCost = (usd: number): string => `$${usd < 10 ? usd.toFixed(2) : usd.toFixed(1)}`

export const fmtTime = (ms: number): string => {
  const s = Math.max(0, Math.round(ms / 1000))
  const h = Math.floor(s / 3600)
  const m = Math.floor((s % 3600) / 60)
  const ss = String(s % 60).padStart(2, '0')
  return h ? `${h}:${String(m).padStart(2, '0')}:${ss}` : `${m}:${ss}`
}

export const elapsed = (a: AgentRun, at: number): number => (a.endedAt ?? Math.max(at, a.startedAt)) - a.startedAt

export const totals = (list: AgentRun[], at: number) => {
  const cost = list.reduce((sum, a) => sum + a.costUsd, 0)
  const tokens = list.reduce((sum, a) => sum + a.tokens, 0)
  if (!list.length) return { cost, tokens, time: 0 }
  const start = Math.min(...list.map(a => a.startedAt))
  const end = Math.max(...list.map(a => a.endedAt ?? Math.max(at, a.startedAt)))
  return { cost, tokens, time: end - start }
}

export const ctxOf = (a: AgentRun): number => (a.contextMax ? Math.min(100, Math.round((a.contextTokens / a.contextMax) * 100)) : 0)
```

```ts
import type { Bar, Steps } from './flow'
import type { Strings } from './i18n'

export const H = 22
const BAR_H = 16
const CRAB_W = 26
// The crab's drawing grid is 30 units wide.
const CRAB_BOX = 30
const CELL = 3
const CRAB_SCALE = 1.1
const FONT = "-apple-system,BlinkMacSystemFont,'SF Pro Text','Segoe UI','Malgun Gothic',sans-serif"
export const ACCENT = '#8f8cf4'
export const DONE = '#5fbf8f'
export const CLAY = '#D97757'
const INK = '#1F1E1D'

export const xml = (s: string): string =>
  s.replace(/[&<>"]/g, c => ({ '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' })[c] ?? c)

// CJK, Hangul, fullwidth forms and emoji advance about 1em.
const WIDE =
  /[\u1100-\u115F\u2E80-\u303E\u3041-\u33FF\u3400-\u4DBF\u4E00-\u9FFF\uA960-\uA97F\uAC00-\uD7A3\uF900-\uFAFF\uFE30-\uFE4F\uFF01-\uFF60\uFFE0-\uFFE6\u{1F300}-\u{1FAFF}\u{20000}-\u{3FFFD}]/u

// Rough advance of system UI text, in em; good enough to size a slot.
const charEm = (ch: string): number =>
  WIDE.test(ch) ? 1 : /[\s.,:;'|!il1()[\]]/.test(ch) ? 0.3 : /[A-Zmw@%]/.test(ch) ? 0.72 : 0.56

export const textWidth = (s: string, size: number): number => [...s].reduce((w, ch) => w + charEm(ch) * size, 0)

// Cuts `s` to fit `maxW` pixels, with an ellipsis when it had to cut.
export const fitText = (s: string, size: number, maxW: number): string => {
  if (textWidth(s, size) <= maxW) return s
  let out = ''
  for (const ch of s) {
    if (textWidth(out + ch + '…', size) > maxW) break
    out += ch
  }
  return out + '…'
}

const clamp01 = (n: number): number => Math.max(0, Math.min(1, Number.isFinite(n) ? n : 0))

// Deterministic noise so the dither does not shimmer between redraws.
const noise = (x: number, y: number): number => {
  const v = Math.sin(x * 12.9898 + y * 78.233) * 43758.5453
  return v - Math.floor(v)
}

// Pure CSS, run by the compositor. Legs step and the body bobs while walking.
const CRAB_CSS = `<style>
.run .la{animation:st .5s steps(1) infinite}.run .lb{animation:st .5s steps(1) infinite -.25s}
.run .bd{animation:bob .5s steps(1) infinite -.125s}

@keyframes st{50%{transform:translateY(-1px)}}@keyframes bob{50%{transform:translateY(1px)}}
@media (prefers-reduced-motion: reduce){.run,.run g{animation:none!important}}
</style>`

// Pixel Clawd: a 24×18 crab on a 30×28 grid.
export const crab = (x: number, y: number, isWalking: boolean, scale = CRAB_SCALE, dim = false): string => {
  const groups: Record<'bd' | 'la' | 'lb', string[]> = { bd: [], la: [], lb: [] }
  const f = (cx: number, cy: number, w: number, h: number, c: string, cls: 'bd' | 'la' | 'lb' = 'bd') =>
    groups[cls].push(`<rect x="${cx}" y="${cy}" width="${w}" height="${h}" fill="${c}"/>`)
  f(7, 10, 16, 12, CLAY)
  f(3, 14, 4, 4, CLAY)
  f(23, 14, 4, 4, CLAY)
  f(9, 12, 2, 2, INK)
  f(19, 12, 2, 2, INK)
  f(7, 22, 2, 4, CLAY, 'la')
  f(17, 22, 2, 4, CLAY, 'la')
  f(11, 22, 2, 4, CLAY, 'lb')
  f(21, 22, 2, 4, CLAY, 'lb')
  const g = (cls: 'bd' | 'la' | 'lb') => `<g class="${cls}">${groups[cls].join('')}</g>`
  return `<g transform="translate(${x},${y}) scale(${scale})" opacity="${dim ? 0.45 : 1}" shape-rendering="crispEdges"><g class="crab${isWalking ? ' run' : ''}">${g('bd')}${g('la')}${g('lb')}</g></g>`
}

// The whole row is one SVG (the desktop wraps sibling elements): title, bar,
// pill, percent and crab; the count and the dismiss are Buttons beside it.
export const rowSvg = (b: Bar, W: number, isWorking: boolean): string => {
  const title = fitText(b.title, 13, Math.max(60, W * 0.4))
  const BAR_X = Math.round(16 + textWidth(title, 13) + 12)
  const BAR_W = Math.max(60, W - BAR_X - 46 - CRAB_W)
  const color = b.isFinished ? DONE : ACCENT
  const y0 = (H - BAR_H) / 2
  const fillW = Math.round(BAR_W * clamp01(b.ratio))
  const runW = Math.round(BAR_W * clamp01(Math.max(b.ratio, b.runRatio)))
  const cols = Math.floor(fillW / CELL)
  const rows = Math.floor(BAR_H / CELL)

  // Dithered fill: sparse at the start, dense toward the head.
  const dots: string[] = []
  for (let c = 0; c < cols; c++) {
    const density = 0.35 + 0.6 * Math.pow(c / Math.max(1, cols), 1.2)
    for (let r = 0; r < rows; r++) {
      if (noise(c, r) < density) dots.push(`<rect class="t${Math.floor(noise(r, c) * 4)}" x="${c * CELL + 1}" y="${r * CELL + 1}" width="2" height="2"/>`)
    }
  }
  // Under way, not yet done: a faint second layer.
  const faint: string[] = []
  for (let c = cols; c < Math.floor(runW / CELL); c++) {
    for (let r = 0; r < rows; r++) {
      if (noise(c + 7, r + 3) < 0.2) faint.push(`<rect class="t${Math.floor(noise(r + 5, c) * 4)}" x="${c * CELL + 1}" y="${r * CELL + 1}" width="1.7" height="1.7"/>`)
    }
  }
  const ticks = b.ticks
    .map(t => Math.round(BAR_W * t))
    .filter(x => x > fillW + 4)
    .map(x => `<rect x="${x}" y="${BAR_H / 2 - 4}" width="1.5" height="8" rx="0.75"/>`)

  const pillW = Math.round(18 + textWidth(b.pill, 11))
  const pillX = Math.max(0, Math.min(BAR_W - pillW, fillW - pillW))
  const percent = `${Math.round(clamp01(b.ratio) * 100)}%`

  return `<svg xmlns="http://www.w3.org/2000/svg" width="${W}" height="${H}" viewBox="0 0 ${W} ${H}">

@media (prefers-reduced-motion: reduce){.t0,.t1,.t2,.t3{animation:none}}
</style>
```

```tsx
import { atom, read, update } from 'claude-code'
import type { EngineInterface, Register } from 'claude-code'

import type { AgentRun } from '../types'
import { costOf, usageTokens, windowOf, type Usage } from './agents'
import { ACCENT, CLAY, DONE, H, barText, rowSvg } from './draw'
import { blankWork, cleanTodos, createTodo, listOf, pickBar, startRequest, updateTodo, withList, type TaskUpdateInput } from './flow'
import { STRINGS, langOf, type Lang } from './i18n'

const PLUGIN = 'work-band'
const PANE = 'work-band-agents'

const work = atom({ plugin: PLUGIN, key: 'work' } as const, blankWork())
const agents = atom({ plugin: PLUGIN, key: 'agents' } as const, [])
const panel = atom({ plugin: PLUGIN, key: 'panel' } as const, { isCompact: false, isDoneCollapsed: false })
const now = atom({ plugin: PLUGIN, key: 'now' } as const, 0)

// Module scope is fine: session.start sets it on every (re)load.
let lang: Lang = 'en'
const tr = () => STRINGS[lang]

async function detectLang($: EngineInterface, option: unknown): Promise<Lang> {
  if (option === 'en' || option === 'ko') return option
  try {
    const settings = (await $.settings.read()) as Record<string, unknown>
    if (typeof settings.language === 'string' && settings.language.trim()) return langOf(settings.language)
  } catch {
    // No settings: the locale decides.
  }
  const locale = (await $.env.get('LC_ALL')) || (await $.env.get('LC_MESSAGES')) || (await $.env.get('LANG'))
  return langOf(locale)
}

// True when the tool ran and answered: not refused by a hook, not an error, not a failure it reported.
const isAnswered = (r: { deny?: string; isError?: boolean; result?: unknown }): boolean =>
  r.deny === undefined && !r.isError && (r.result as { success?: unknown } | undefined)?.success !== false

// Opens the agents pane, or closes it when it is up; true when it ends up open.
async function togglePane($: EngineInterface): Promise<boolean> {
  const isOpen = (await $.ui.panes()).some(p => p.id === PANE)
  if (isOpen) {
    await $.ui.close({ id: PANE })
    return false
  }
  const at = await $.clock.now()
  await update($, now, () => at)
  await $.ui.open({ id: PANE, title: tr().pane })
  return true
}

export const register: Register = (on, options) => {
  on('session.start', async ($, e, next) => {
    const started = await next(e)
    lang = await detectLang($, options.language)
    // Ticks the running agents' clocks; quiet when nothing runs.
    $.clock.every(1000, () => {
      void (async () => {
        const list = await read($, agents)
        if (!list.some(a => a.status === 'running')) return
        const at = await $.clock.now()
        await update($, now, () => at)
      })()
    })
    return started
  })

  // To-do lists, the main session's and each subagent's, read as they are written.
  on('tool.call', { tool: 'TodoWrite' }, async ($, e, next) => {
    const result = await next(e)
    if (!isAnswered(result)) return result
    const todos = cleanTodos((e as unknown as { todos?: unknown }).todos)
    await update($, work, w => withList(w, e.agentId, todos))
    return result
  })

  on('tool.call', { tool: 'TaskCreate' }, async ($, e, next) => {
    const result = await next(e)
    if (!isAnswered(result)) return result
    const input = e as unknown as { subject?: unknown; activeForm?: unknown }
    const id = (result.result as { task?: { id?: unknown } } | undefined)?.task?.id
    await update($, work, w => {
      const todos = createTodo(listOf(w, e.agentId), id, input.subject, input.activeForm)
      return todos ? withList(w, e.agentId, todos) : w
    })
    return result
  })

  on('tool.call', { tool: 'TaskUpdate' }, async ($, e, next) => {
    const result = await next(e)
    if (!isAnswered(result)) return result
    const input = e as unknown as TaskUpdateInput
    await update($, work, w => {
      const todos = updateTodo(listOf(w, e.agentId), input)
      return todos ? withList(w, e.agentId, todos) : w
    })
    return result
  })

  // A prompt typed while idle starts a new request; a slash command or a prompt
  // typed into a running turn does not.
  on('prompt.submit', async ($, e, next) => {
    if (!e.command && e.turnId === undefined) {
      const at = await $.clock.now()
      await update($, work, w => startRequest(w, at))
    }
    return next(e)
  })

  on('agent.spawn', async ($, e, next) => {
    const started = await next(e)
    if (started.deny !== undefined) return started
    const at = await $.clock.now()
    await update($, agents, list => {
      const run: AgentRun = {
        id: started.agentId ?? e.tool_use_id,
        agentId: started.agentId,
        type: e.subagentType,
        description: e.description,
        model: started.model,
        status: 'running',
        startedAt: at,
        contextTokens: 0,
        contextMax: windowOf(started.model),
        tokens: 0,
        costUsd: 0,
        steps: 0,
      }
      return [...list.filter(a => a.id !== run.id), run].slice(-200)
    })
    await update($, now, () => at)
    await update($, work, w => (w.isHidden ? { ...w, isHidden: false } : w))
    return started
  })

  // Each model request of a subagent: live context, tokens and cost.
  on('turn.step', async function* ($, e, next) {
    const result = yield* next(e)
    const agentId = e.agentId
    const usage = result.usage
    if (!agentId || !usage) return result
    const model = usage.model || e.model
    await update($, agents, list =>
      list.map((a): AgentRun =>
        a.agentId !== agentId
          ? a
          : {
              ...a,
              model,
              effort: typeof e.effort === 'string' ? e.effort : a.effort,
              status: 'running',
              endedAt: undefined,
              contextTokens: usageTokens(usage),
              contextMax: windowOf(model),
              tokens: a.tokens + usageTokens(usage),
              costUsd: a.costUsd + costOf(model, usage, true),
              steps: a.steps + 1,
            },
      ),
    )
    return result
  })

  on('turn.complete', async ($, e, next) => {
    const agentId = e.agentId
    if (agentId) {
      const at = await $.clock.now()
      await update($, agents, list =>
        list.map((a): AgentRun => {
          if (a.agentId !== agentId) return a
          // A run whose steps went unseen still gets the turn's own sum.
          const usage = a.steps === 0 ? (e.usage as (Usage & { model?: string }) | null | undefined) : undefined
          return {
            ...a,
            status: e.reason === 'answer' ? 'done' : 'failed',
            endedAt: at,
            ...(usage ? { model: usage.model || a.model, tokens: usageTokens(usage), costUsd: costOf(usage.model || a.model, usage, false) } : {}),
          }
        }),
      )
      await update($, now, () => at)
      // A finished run's own list is done with: the panel shows it full.
      await update($, work, w => {
        if (!Object.hasOwn(w.agentTodos, agentId)) return w
        const { [agentId]: _gone, ...rest } = w.agentTodos
        return { ...w, agentTodos: rest }
      })
    }
    return next(e)
  })

  on('ui.render', { component: 'AbovePrompt' }, async ($, e, next) => {
    if (e.props.hasSurvey) return next(e)
    const s = tr()
    const w = await read($, work)
    const list = await read($, agents)
    const bar = pickBar(w, list, s)
    if (!bar) return next(e)
    // Draw this row with the other mods' bands beneath it. Claude Code's own
    // placeholder ({ type: 'engine' }) is never nested: the desktop drops a band that nests it.
    const drawn = await Promise.resolve(next(e)).catch(() => null)
    const below = drawn && typeof drawn === 'object' && (drawn as { type?: string }).type !== 'engine' ? drawn : null

    const ui = $.ui.resolve(e)
    const { Box, Text, Button } = ui
    const running = list.filter(a => a.status === 'running').length
    const percent = `${Math.round(bar.ratio * 100)}%`
    const crew = running ? <Button key="work-band-agents" label={`×${running}`} plain onPress={() => void togglePane($)} /> : null
    const dismiss = (
      <Button
        key="work-band-dismiss"
        label="✕"
        plain
        role="dismiss"
        onPress={() => update($, work, prev => (bar.isFlow ? { ...prev, flow: null, isHidden: true } : { ...prev, isHidden: true }))}
      />
    )

    // The terminal's element table is completed with an `Svg` that draws nothing: test the surface too.
    if (e.surface !== 'terminal' && 'Svg' in ui) {
      const { Svg } = ui
      // About 8 CSS px per reported column; the rest is the count, the dismiss and their gaps.
      const width = Math.max(180, Math.min(1600, (e.props.bodyColumns || 100) * 8 - 96))
      const alt = [bar.title, bar.pill, percent, bar.doing].filter(Boolean).join(' · ')
      return (
        <Box flexDirection="column">
          <Box flexDirection="row" alignItems="center" gap={1}>
            <Svg source={rowSvg(bar, width, running > 0)} alt={alt} width={width} height={H} />
            {crew}
            {dismiss}
          </Box>
          {below}
        </Box>
      )
    }

    const cols = e.props.bodyColumns
    const titleW = Math.max(8, Math.min(30, bar.title.length + 2, Math.floor(cols / 3)))
    const width = Math.max(6, Math.min(40, cols - titleW - 32))
    const color = bar.isFinished ? DONE : ACCENT
    return (
      <Box flexDirection="column">
        <Box flexDirection="row" gap={2}>
          <Box width={titleW} flexShrink={0}>
            <Text color={color}>● </Text>
            <Text wrap="truncate-end">{bar.title}</Text>
          </Box>
          <Text color={color}>{barText(bar.ratio, width)}</Text>
          <Text bold>{bar.pill}</Text>
          <Text dimColor>{percent}</Text>
          <Text color={CLAY}>▣</Text>
          {crew}
          {dismiss}
        </Box>
        {below}
      </Box>
    )
  })
}
```

```tsx
// A superpowers skill, called by the model or typed as a slash command, moves
// the flow; an executing skill handed a plan path reads the plan's task count.
async function applySkill($: EngineInterface, name: unknown, args: unknown): Promise<void> {
  const stage = skillStage(name)
  if (!stage) return
  const w = await update($, work, prev => ({ ...prev, flow: advance(prev.flow, stage, args) }))
  const path = mdPathOf(args)
  if (stage !== 'build' || !w.flow || w.flow.planTasks || !path) return
  try {
    const md = await $.fs.read(path)
    if (typeof md === 'string') await update($, work, prev => (prev.flow ? { ...prev, flow: withPlan(prev.flow, md) } : prev))
  } catch {
    // An unreadable plan: the to-do list counts the tasks.
  }
}

// A file the main session wrote or edited.
async function applyFile($: EngineInterface, path: unknown, content?: unknown): Promise<void> {
  await update($, work, w => {
    const flow = onWrite(w.flow, path, content)
    return flow === w.flow ? w : { ...w, flow }
  })
}
```

## 무엇을 보여 주나

- **superpowers 흐름**: `brainstorming` → spec 문서 → `writing-plans` → 구현(`subagent-driven-development`, `executing-plans`, `test-driven-development`) → `requesting-code-review` → `finishing-a-development-branch`를 6칸 눈금으로 보여 줍니다. 구현 칸은 계획의 작업 수 중 끝난 수만큼 채워집니다. 제목은 plan, spec 문서 제목, brainstorming 주제 순입니다.
- **하네스만 쓸 때**: Claude의 할 일 목록(`Tasks 3/5`), 목록이 없으면 이번 요청의 서브에이전트(`Agents 1/2`)를 보여 줍니다. 간단한 요청에는 막대가 뜨지 않습니다.
- **×N**: 실행 중인 서브에이전트 수입니다. 누르거나 `/work-band`를 입력하면 에이전트 패널(모델·effort, 컨텍스트, 예상 비용, 시간, 서브에이전트의 할 일 진행)을 열고 닫습니다.
- **✕**: superpowers 흐름은 끝내고, 하네스 막대는 새 데이터가 올 때까지 숨깁니다. 끝난 막대는 다음 요청을 보낼 때 사라집니다.

비용은 토큰 수와 내장 가격표로 계산한 추정치입니다.
